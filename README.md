# Sample repository

A tiny Python sample used to test Agent Forge against a real forge.

## Files

- `calc.py` — `add(a, b)` and `subtract(a, b)`.
- `greet.py` — `greet(name)` returns `Hello, <name>!`.
- `test_sample.py` — unit tests for both modules.

## Check

Run the tests (fast, standard library only):

```
python -m unittest -q
```
